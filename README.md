### Featured Projects & Hackathon Works

- **[Escapture](https://github.com/gabonjohngabriel/escapture)** *(Build Off Hackathon)*  
  A cyberbullying evidence-preservation and case escalation platform built for BulSU students, pairing a Next.js / TypeScript web app (PostgreSQL, Drizzle ORM, Better Auth) with a Chrome Manifest V3 extension that runs tamper checks and SHA-256 verification before storing captures in a private vault.  
  *My focus:* Figma-to-code UI redesign across the landing page, auth flow, and app shell; mobile responsive navigation; privacy blur mode; passkey capture grants; and authority case-referral workflows.

- **[AWS Student Builder Group – BulSU Website](https://awssbgbulsu.cloud)**  
  The official community site for AWS SBG BulSU (Bulacan State University – CICT), built with Next.js and Tailwind CSS.  
  *My focus:* Collaborated on UI/UX design and front-end development for the group's web presence.

- **[AGAPAY | BulSU Campus Help Desk Ticketing System](https://github.com/gabonjohngabriel/agapay)**  
  An object-oriented campus help desk system in Java (Maven, JUnit 5) supporting user and support-staff workflows across university departments (CICT, CON, CAL) with custom data structures, notifications, and ticket archiving.

- **[ALABPOINT | ATM and Banking System](https://github.com/gabonjohngabriel/atmbankingsystem)**  
  A console-based ATM and banking simulation in Java (Maven) built on custom linked data structures (`AccountList`, `TransactionList`) for account creation, authentication, deposits, withdrawals, fund transfers, transaction history, and bank reports.
